    NICE신용평가 / NICE평가정보

    NICE 그룹
    비즈월드경제2026-08-06 🆕

    NICE평가정보, 쿠콘과 MOU 체결…데이터 기반 금융 혁신 앞장

    NICE평가정보가 비즈니스 데이터 플랫폼 기업 쿠콘과 정보서비스 유통 확대 및 데이터 기반 신규사업 발굴을 위한 전략적 업무협약을 체결했다. 양사는 각사가 보유한 금융·비금융 데이터를 연계해 새로운 데이터 상품과 서비스를 공동 기획·유통할 계획이다.

    영향: 신용·비즈니스 데이터 결합 상품 및 API 사업 확대 가능성이 커져, 당사 데이터 경쟁력과 서비스 라인업을 재점검할 필요가 있다.
    대응: 쿠콘·NICE 데이터 제휴 구조와 공급·수익배분 모델을 분석해, 당사의 금융·비금융 데이터 융합 파트너십 및 API 전략에 반영할 것을 제안한다.
    바이라인네트워크2026-08-03

    블루어드, NICE평가정보와 토큰증권 사업 협력 업무협약 체결

    블루어드와 NICE평가정보가 토큰증권(STO) 사업 협력을 위한 업무협약을 체결했다. 양사는 기업 보유 자산 기반 투자계약증권·신탁수익증권 발행을 목표로 STO 구조 설계와 관련 데이터·평가 서비스를 공동으로 추진한다.

    영향: NICE가 STO 밸류체인에 본격 진입하면서, 우리도 온체인 자산·토큰증권 관련 데이터·평가 모델과 레퍼런스 확보 경쟁에 대비해야 한다.
    대응: STO 관련 규제·시장 동향과 NICE-블루어드 역할 분담을 정리해, 당사의 기업·자산 데이터 기반 STO 평가·데이터 서비스 진입 시나리오를 마련하자.

    한국평가데이터 (KODATA)

    구 한국기업데이터(KED)
    뉴시스2026-08-07 🆕

    인천시설공단, 지방공기업 경영평가서 '우수' 등급

    인천시설공단이 2025년 지방공기업 경영평가에서 우수 등급을 받았다. 공단은 2년 연속 ESG 우수기업에 선정됐고, 한국평가데이터와 중소기업 지원 업무협약을 맺어 인천지역 중소기업 제품 구매 확대 등 지역경제 활성화를 추진하고 있다.

    영향: KODATA가 공공기관과의 협력사·지역 중소기업 지원 모델을 구축한 사례로, 당사의 지자체·공공부문과의 ESG·중소기업 데이터 협력사업 기획에 참고가 된다.
    대응: 인천시설공단-KODATA 협약 내용을 조사해 공공기관 구매·ESG 연계 데이터 사업 구조를 벤치마킹하고, 유사 지자체·공단 대상 제안 패키지 구상을 검토하자.
    딜사이트TV2026-08-03

    [은행 Talk Talk] 신한은행, 금융권 최초 감정평가서 AI 점검 外

    우리은행이 스타트업 성장 지원 프로그램 ‘2026 2nd S.Stage’를 진행하며 토스뱅크와 함께 한국평가데이터, 현대홈쇼핑, DB손해보험, LG화학 등이 파트너로 참여한다. KODATA는 중소기업의 신용·재무 정보 제공을 통해 금융·비금융사가 협력하는 개방형 생태계에 데이터를 공급한다.

    영향: KODATA가 빅테크·은행·대기업이 결합된 스타트업 지원 플랫폼에 참여하면서, 당사의 오픈 이노베이션·스타트업 데이터 사업 포지셔닝과 제휴 네트워크 재정비 필요성이 커진다.
    대응: 해당 프로그램 구조와 KODATA의 역할을 파악해, 우리은행·토스뱅크류 플랫폼과의 데이터 제휴·공동 프로그램 참여 가능성을 검토하자.

    KCB (코리아크레딧뷰로)

    화이트페이퍼2026-08-06 🆕

    기업은행, 비대면 햇살론…금리 연 6.0%·한도 1000만원

    IBK기업은행이 서민·취약계층을 위한 비대면 대출 상품 ‘i-ONE 햇살론 특례보증’을 출시했다. 대상은 연소득 3500만원 이하이면서 NICE·KCB 신용평점 하위 20% 이하인 급여소득자로, 금융당국 정책보증과 연계해 최대 1000만원까지 낮은 금리로 지원한다.

    영향: 정책·서민금융 영역에서 NICE·KCB 개인 신용점수가 공식 기준으로 활용되면서, 신용평가모형의 사회적 영향력과 규제 연계성이 계속 확대되고 있다.
    대응: 햇살론 특례보증의 세부 심사 기준과 데이터 활용 범위를 점검해, 정책금융용 신용지표·보조지표 상품화 가능성을 검토하자.
    더파워뉴스2026-07-27

    매출·상권 보고 대출 심사…소상공인 신용평가 16개 은행으로 확대

    금융당국이 소상공인 매출과 상권 정보를 활용한 새로운 신용평가체계를 16개 은행으로 확대한다. 이 체계는 나이스평가정보와 코리아크레딧뷰로, 서울보증보험 등이 참여해 카드·매출·상권 데이터를 결합해 SCB 성장등급을 산출하고, 10월 출시 예정인 특화 대출상품에 적용된다.

    영향: NICE·KCB가 참여하는 소상공인 성장등급이 사실상 표준화되면서, 우리도 자영업·소상공인용 대체데이터 신용평가 모델 개발과 은행 제휴 전략을 강화해야 한다.
    대응: SCB 성장등급 산정 로직과 참여기관 데이터 소스를 분석해, 당사의 VAN·POS·상권 데이터 결합 모델과 은행 대상 대안평가 솔루션 제안 방향을 정교화하자.
