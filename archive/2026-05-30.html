    한국평가데이터 (KODATA)

    구 한국기업데이터(KED)

    금투협·벤처기업협회·한국평가데이터, '생산적 금융' 3자 MOU 체결

    한국평가데이터가 금융투자협회·벤처기업협회와 3자 업무협약을 맺고 벤처·스타트업 전용 기업가치평가 DB 및 AI 첨단산업 데이터 공동 구축에 착수했다. '생산적 금융' 흐름에 맞춘 데이터 생태계 확장 행보다.

    영향: KODATA가 벤처·혁신금융 데이터 허브로 포지셔닝을 강화. 우리 혁신금융 데이터 파트너십 후보를 선제 검토하지 않으면 데이터 제휴 시장에서 밀릴 수 있다.
    대응: 벤처기업협회·금투협 채널과의 데이터 제휴 가능성 타진 + KODATA 가치평가 DB 상품화 타임라인 추적.

    KCB (코리아크레딧뷰로)

    ZDNet Korea 2026-05-20

    카카오페이 스코어(KCB 공동개발), 주금공 전세대출보증 프로세스에 공식 도입

    KCB와 카카오페이가 공동 개발한 대안신용평가모형 '카카오페이 스코어'가 한국주택금융공사(주금공) 전세대출보증 심사 프로세스에 공식 적용됐다. 송금·결제 데이터와 마이데이터를 AI로 결합해 금융이력 부족 차주의 상환 능력을 포착한다.

    영향: 민간 CB(KCB) 데이터가 공적 주택보증 심사에 직접 연결되는 첫 사례. KCB가 공공금융 API 채널을 선점하며 개인신용평가 시장 입지를 확대 — 경쟁 CB사 대비 레퍼런스 우위 강화로 직결.
    대응: 우리 CB 데이터의 주금공·SGI서울보증 연계 가능성 타진 착수 + 카카오페이 스코어 보증 승인율 등 성과 지표 모니터링.

    국내 최초 전업 개인사업자 CB
    뉴데일리 2026-04-15

    한국평가정보, 홈택스 연동 사업장 60만 곳 돌파

    한국평가정보(KCS)가 국세청 홈택스 정보 연동 사업장 60만 곳을 돌파했다고 밝혔다. 개인사업자 전업 CB 중 최대 규모로, 매출·납세 데이터를 실시간에 가깝게 확보해 '연결 데이터' 기반 신용평가 전환을 본격화한다. 연내 100만 곳이 목표다.

    영향: 개인사업자 대안신용평가의 핵심 자산인 국세청 실매출 데이터를 대규모로 선점. 우리 개인사업자 CB 사업의 데이터 확보 전략에 직접적 위협이자 벤치마크.
    대응: 홈택스 연동 데이터 확보 방안 검토 + KCS 100만 사업장 목표 달성 속도·제휴 금융사 동향 추적.
