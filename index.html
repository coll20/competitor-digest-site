    NICE신용평가 / NICE평가정보

    NICE 그룹
    전자신문2026-03-26

    NICE평가정보, 업계 최초 '비대면 채무조정 중개 서비스' 출시

    NICE평가정보가 운영하는 본인신용정보 종합관리 플랫폼 '나이스지키미'를 통해 업계 최초로 비대면 채무조정 중개 서비스를 2026년 3월 26일 출시했다. 채무조정 안내부터 신청·심사·결과 통지·상환까지 전 과정을 온라인 기반으로 지원하며, 2024년 10월 시행된 개인채무자보호법에 따른 금융기관의 채무조정 안내·협의 절차 의무화 수요에 대응해 마련됐다. 금융기관은 별도 전산 구축 없이 채무조정 절차를 자동화할 수 있으며, NICE가 보유한 신용보고서·소득정보·금융거래 정보를 바탕으로 채무자의 변제 능력을 객관적으로 산출한다. 현재 웰릭스에프앤아이대부·동양자산관리대부 등을 시작으로 서비스 이용기관이 빠르게 확대 중이다.

    영향: 채무조정 B2B 인프라 플랫폼 시장 선점 — NICE의 신용정보·플랫폼 역량 결합으로 포용금융 서비스 영역 확장. 금융기관 필수 이용 서비스 자리매김 시 채무 관련 데이터 독점 심화 가능성.
    대응: 당사도 개인채무자보호법 관련 규제 대응 서비스 라인업을 즉시 점검하고, 비대면 채무조정 인프라 구축 가능성 및 B2B 신규 시장 진입 전략 수립 권고.

    한국평가데이터 (KODATA)

    구 한국기업데이터(KED)

    한국평가데이터, 1,400만 기업정보 담은 API 포털 'KOapinet' 출시

    한국평가데이터(KODATA)가 국내 최대 규모의 기업정보 1,400만 건을 API 형태로 실시간 제공하는 종합 포털 서비스 'KOapinet'을 2026년 2월 10일 공식 출시했다. 오픈API 기반 인증키 방식으로 고객사 시스템과 직접 연동 가능하며, 맞춤형 API 방식 도입으로 다양한 고객사 시스템과의 유기적 연결 및 정보 보안 수준 강화가 특징이다. 기업정보 DB를 API 경제 형태로 개방함으로써 B2B 데이터 플랫폼으로의 전환을 본격화했다.

    영향: 기업정보 API 경제 선점 — 고객사 기술 연동 심화로 전환 비용 상승 및 데이터 의존도 강화. B2B 신용 데이터 시장에서 플랫폼 잠금(lock-in) 효과 창출 가속.
    대응: 당사 기업정보 API 상품화 전략을 긴급 재검토하고, 오픈API 플랫폼 구축을 통한 고객사 연동 서비스 경쟁력 확보 방안 마련 권고.
