    앤트로픽 서울 사무소 개설 — NAVER·삼성SDS·LG CNS Claude 전사 도입·과기부 MOU·국가 AI 연구 컨소시엄·한국 3번째 아태 거점
    Anthropic 2026-06-17 국내 보도

    앤트로픽, 서울 사무소 개설 — NAVER Claude Code 전사 도입·삼성SDS·LG CNS·넥슨·한화솔루션·채널코퍼레이션 파트너십·과기부 MOU·국가 AI 연구 컨소시엄 출범·도쿄·벵갈루루 이은 세 번째 아태 거점

    앤트로픽(Anthropic)이 2026년 6월 17일 대한민국 서울에 공식 법인(Anthropic Korea)을 설립하고 18일 개소식을 가졌다. 스노우플레이크 코리아(Snowflake Korea) 대표 출신의 최기영(KiYoung Choi)이 대표이사로 선임됐으며, 서울 사무소는 도쿄·벵갈루루에 이은 앤트로픽의 세 번째 아시아·태평양 법인이다. 개소와 동시에 NAVER가 Claude Code 전사 도입을 확정했으며, 삼성SDS는 Claude Cowork·Claude Code를, LG CNS·넥슨·한화솔루션·채널코퍼레이션이 각각 Claude 기반 업무 자동화·개발 툴체인 통합을 발표했다. 앤트로픽은 과학기술정보통신부와 MOU를 체결해 국가 AI 연구 인프라 지원에 합의했으며, KAIST·고려대·연세대·포스텍 소속 60명 이상의 연구자로 구성된 국가 AI 연구 컨소시엄을 출범시켰다. 앤트로픽은 한국 시장에서 Claude 4 모델군을 기반으로 에이전트·코딩·엔터프라이즈 워크플로우를 중심으로 사업을 전개할 방침이며, 정부 및 학계와의 긴밀한 협력을 통해 한국형 AI 생태계를 구축하겠다는 의지를 명확히 했다.

    글로벌 의미: 글로벌 프론티어 AI 기업이 한국에 법인을 설립하고 국내 최대 IT 기업들과 동시다발 파트너십을 체결한 것은, 한국이 아시아 AI 전환 허브로 부상하고 있음을 국제적으로 인정받는 사건이다 — Claude 생태계가 국내 기업 개발 표준으로 자리잡을 경우 소프트웨어 공급망의 AI 의존도가 급속히 높아진다.
    💡 테크핀 연관: 앤트로픽 한국 법인 설립과 NAVER·삼성SDS Claude 전사 도입은 테크핀에게 즉각적인 기회를 의미한다 — 더존비즈온 ERP 생태계의 주요 파트너들이 Claude를 업무 표준으로 채택하게 되면, 테크핀의 CSS·EWS·AI 경영진단보고서에 Claude 에이전트를 통합하는 것이 '파트너 요청'이 아닌 '생태계 표준 대응'으로 자리매김할 수 있다 — 앤트로픽 코리아와의 공식 파트너십 협의를 3분기 내 착수하고, Claude Code 기반 신용 분석 에이전트 PoC를 연내 추진할 것을 권고한다.

    Motley Fool 2026-06-19 국내 보도

    아마존 CEO "Trainium 외부 판매 시 연 $50B 사업" — 커스텀 실리콘(Trainium·Graviton·Nitro) ARR $20B 돌파·YoY 100%+ 성장·오픈AI 2GW·앤트로픽 5GW 약정·유럽 소버린 클라우드 성장 동력

    아마존 CEO 앤디 재시(Andy Jassy)가 2026년 6월 18~19일 인터뷰를 통해 아마존 자체 AI 칩(Trainium·Graviton·Nitro)의 현재 연간 반복 매출(ARR)이 200억 달러($20B)를 초과했으며 전년 대비 100% 이상 성장 중이라고 공개했다. 재시 CEO는 특히 "Trainium을 외부 기업에 직접 판매할 경우 연간 500억 달러($50B) 규모의 사업이 될 것"이라고 언급하며 칩 외부 판매 가능성을 처음으로 공개 시사했다. 현재 아마존의 커스텀 실리콘은 주로 AWS 내부 워크로드에 사용되지만 오픈AI(약 2GW 컴퓨팅 약정)·앤트로픽(약 5GW 약정) 등 대형 AI 기업들이 이미 외부 고객으로 대규모 Trainium 기반 컴퓨팅을 활용 중이다. 재시는 유럽 내 데이터 주권(Data Sovereignty) 요건을 충족하는 소버린 클라우드 수요가 커스텀 실리콘의 주요 성장 동력이 될 것이라고 강조했다. Trainium이 외부 판매 상품으로 출시될 경우 NVIDIA·AMD와 함께 AI 칩 시장이 3파전으로 재편되며, 클라우드 GPU 단가 경쟁이 한층 치열해질 전망이다.

    글로벌 의미: 아마존이 내부 전용으로 쓰던 AI 칩을 외부에 판매하기 시작하면 NVIDIA 독점 구도에 최대 도전자가 등장한다 — 클라우드 AI 칩 3파전이 본격화될수록 추론 단가 하락이 가속화되고, AI 모형 운용 비용이 전 산업에 걸쳐 낮아지는 구조적 변화가 시작된다.
    💡 테크핀 연관: 아마존 Trainium 외부 판매가 현실화되면 AWS Trainium 기반 추론 서비스가 NVIDIA 클라우드 대비 구조적 원가 우위를 가질 가능성이 높다 — 테크핀의 CSS·EWS 추론 파이프라인 클라우드 인프라 계약 갱신 시, AWS Trainium·AMD Instinct·NVIDIA GPU 3종의 에이전트당 비용($/agent-call)을 비교 시뮬레이션해 최적 벤더를 선택하는 인프라 비교 검토를 3분기 중 착수할 것을 권고한다.

    Vercel Eve 오픈소스 TypeScript 에이전트 프레임워크 공개 — Apache-2.0·파일 기반 아키텍처·6종 프로덕션 기본 내장·v0 내부 검증 완료
    Vercel Blog 2026-06-17

    Vercel, 오픈소스 AI 에이전트 프레임워크 'Eve' 공개 — Apache-2.0·TypeScript 파일 기반·내구성 실행·샌드박스·인간 승인·OpenTelemetry 기본 내장·v0 프로덕션 검증

    Vercel이 2026년 6월 17일 런던 Vercel Ship 컨퍼런스에서 오픈소스 TypeScript AI 에이전트 프레임워크 'Eve'를 Apache-2.0 라이선스로 공개했다. Eve는 파일 기반 아키텍처를 채택해 각 에이전트를 하나의 디렉터리로 표현한다: instructions.md(에이전트 역할 정의), agent/tools/(외부 API 호출 도구), agent/skills/(재사용 가능한 하위 에이전트 모듈)로 구성된다. 프로덕션 환경에서 요구되는 6가지 기능(내구성 워크플로우 실행, 샌드박스 코드 실행, 인간 승인 게이트, 멀티채널 메시지, OpenTelemetry 기반 트레이싱, 평가 프레임워크)을 기본 내장해 처음부터 엔터프라이즈 수준 에이전트를 구축할 수 있도록 설계됐다. Vercel은 자사의 v0 AI 코드 생성 서비스와 내부 에이전트 플릿에 이미 Eve를 프로덕션 환경에서 운영 중이며, 오픈소스 공개로 외부 개발자 생태계를 키우는 전략이다. 기존 LangChain·CrewAI 대비 파일 구조가 단순하고 Claude Code 개발 환경과 자연스럽게 연동된다는 점이 주요 차별화 포인트로 부각됐다.

    글로벌 의미: Vercel처럼 프로덕션 검증 완료 에이전트 프레임워크가 Apache-2.0으로 오픈소스화되면, 에이전트 개발 진입 장벽이 대폭 낮아진다 — TypeScript 생태계 기반이어서 웹 개발 팀도 즉시 AI 에이전트를 도입할 수 있게 되며, 특수 ML 인력 없이도 에이전트 워크플로우를 구축하는 시대가 열린다.
    💡 테크핀 연관: Vercel Eve는 테크핀이 CSS·EWS 에이전트 파이프라인의 프로토타입을 낮은 비용으로 빠르게 검증하는 데 직접 활용할 수 있는 오픈소스 도구다 — instructions.md 기반 역할 정의·내구성 실행·인간 승인 게이트가 기본 내장돼 있어, 신용 분석 에이전트의 킬스위치·감사 로그 설계를 SR 26-2 요건에 맞게 구현하는 비용과 시간을 크게 단축할 수 있으며, 4분기 에이전트 PoC 도구 목록에 우선 포함할 것을 권고한다.
